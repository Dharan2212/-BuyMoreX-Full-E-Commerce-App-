# -BuyMoreX-Full-E-Commerce-App-
WebsiteMERN Stack | TailwindCSS | Stripe | Docker | Postman

Architected and built a full-stack E-Commerce application using the MERN stack (MongoDB, Express, React, Node.js), demonstrating proficiency in full-stack development.

Engineered a secure backend with Node.js and Express.js, including JWT-based user authentication for sign-up and login.

Designed and managed a MongoDB database on Atlas to handle product, user, and order data efficiently.

Integrated the Stripe API to process payments, providing a secure and seamless checkout experience.

Containerized the application using Docker and implemented a CI/CD pipeline with GitHub Actions for automated testing and deployment.
